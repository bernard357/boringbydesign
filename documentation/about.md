# About

_Boring by design_ is a blog and a book about building simple, durable systems
on purpose. This is a placeholder page created during project scaffolding.

The site is authored in Markdown under `documentation/`, built as a static site
with [VitePress](https://vitepress.dev/), and published to
[GitHub Pages](https://docs.github.com/en/pages) via GitHub Actions on every
push to `main`.
