# Hello, boring world

This is the first post. It exists mainly to prove the pipeline — a flat URL,
a build-time index entry, and a home page that lists it. Replace it with real
writing whenever you like.

## What "boring by design" means

Boring is a compliment here. It means choosing proven, predictable tools and
simple structures on purpose, so the interesting part stays the ideas rather
than the plumbing. Each post stands on its own; the only thread between them is
that principle.
